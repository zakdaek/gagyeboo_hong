월별 가계 수입 · 지출

월급·월급 외 수입·고정비용·변동지출 목록과 대출·할부·예적금·입주 준비의 현금흐름을 조회 월에 맞춰 표시합니다.

부부 월급 실수령액 · 월별 입력

위의 조회 월을 먼저 선택하고, 해당 월에 실제로 받은 실수령 월급을 입력하세요. 입력한 달에만 반영되며 다른 달에는 자동 복사되지 않습니다. 아직 입력하지 않은 달의 월급은 0원으로 계산합니다.

내 월급

아내 월급

저장한 월별 월급

새 달이 되면 월급 입력란은 빈칸으로 시작하며, 저장하기 전에는 수입 0원으로 표시됩니다. 위의 조회 월에서 지난달을 선택해 급여를 확인하거나 수정할 수 있습니다. 이전 버전의 전체 달 적용 월급은 최초 실행 시 현재 월 한 달로만 이전합니다.

월급 외 수입 등록

부업·상여금·임대료·지원금·환급금처럼 월급 외 통장에 들어오는 수입을 등록하세요. 실제 수령할 금액(세후)을 입력하며, 일회성 또는 매월 반복 수입을 선택할 수 있습니다.

비워두면 매월 계속 반영

조회 월에 해당하는 월급 외 수입

매월 반복은 첫 수입월부터 종료월까지 매달 같은 금액을 반영합니다(31일 등 해당 날짜가 없는 달은 말일로 계산). 금융상품 만기금은 4번 메뉴에서 이미 자동 반영되므로 중복 등록하지 마세요.

고정비용 입력

조회 월을 기준으로 고정비가 표시됩니다. 해당 월만 적용하거나 시작월부터 매월 반복하도록 선택하세요.

빈칸이면 매월 계속 적용

조회 월 고정비용

기존 버전에서 등록한 고정비는 시작월 정보가 없어 이전과 동일하게 매월 반복으로 표시합니다. 기간을 제한하려면 해당 항목의 수정 버튼을 사용하세요.

변동지출 입력

변동지출은 지출일이 속한 달에만 반영되며, 조회 월의 항목만 아래 목록에 표시됩니다.

조회 월 변동지출

자동 반영 지출 · 금융상품 만기 수입

2번 대출 · 3번 카드 할부 · 4번 금융상품 · 6번 입주 준비에 등록된 일정으로 생성됩니다. 별도 지출 등록은 필요하지 않습니다.

조회 월 기준 자동 계산

자동 내역은 각 원본 메뉴에서 수정하거나 삭제하면 즉시 갱신됩니다. 대출 상환·할부·적금 납입은 예정액이며 실제 결제 여부를 확인하지 않습니다. 적금·예금의 납입은 생활비 소비가 아닌 자금 이동(현금유출)이고 만기 수령액은 세전 예상 현금유입입니다.

월별 대출 상환금 총액

등록한 모든 대출의 해당 월 원금·이자 상환 예정액을 합산합니다. 변동금리 변경 내역도 자동 반영됩니다.

대출 등록

상환일은 대출시작일의 다음 달 같은 날부터로 가정합니다(해당 일자가 없는 달은 말일). 최초 금리를 등록한 후 상품별 「금리 변경 등록·이력」에서 금리 적용일과 변경 금리를 입력할 수 있습니다. 적용일부터 이자를 구간별로 나누고 남은 원금·잔여 회차로 향후 월 납입금을 다시 계산합니다. 연체·중도상환·수수료는 반영하지 않은 추정치이며 실제 은행 방식과 다를 수 있습니다.

카드 할부 등록

무이자 할부를 기준으로 월별 금액을 나눕니다. 유이자 할부 수수료는 포함하지 않습니다.

할부 현황

예금 · 적금 · 금융상품 등록

상품 정보 입력 시 예상 만기금이 표시됩니다.

상품 등록 후 「금리 변경 등록·이력」에서 적용일과 새 금리를 추가하면 금리 적용 기간별로 예상 이자를 다시 계산합니다. 적금은 만기일 전까지 매월 같은 날 납입하며 금리가 변해도 약정 월 납입원금은 그대로 유지합니다. 단리는 일할 계산, 월복리·연복리는 구간별 복리 계수를 곱한 추정치입니다. 세금·우대금리·은행별 약관·반올림은 반영하지 않습니다. 월별 납입액은 자동 현금유출로, 만기 예상 수령액은 만기월의 예상 현금유입으로 자동 반영합니다(세전 금액).

금융상품 목록

우리 집 현금흐름

월별 수입 · 유출 비교

총 유입(월별 입력 급여 + 월급 외 수입 + 예상 만기 수령액)총 유출

그래프를 좌우로 밀어 12개월 전체를 확인하세요.

급여는 입력한 월에만 반영되며 미입력 월은 0원으로 계산합니다. 월급 외 반복 수입은 등록한 기간 동안 발생한다고 가정합니다. 대출 원리금, 카드 할부, 적금 월 납입·예금 예치와 입주 준비의 현금·카드 청구액은 자동으로 현금유출에, 예·적금의 세전 예상 만기금은 만기월 현금유입에 반영됩니다. 원본과 1번 메뉴에 중복 등록하지 마세요. 실제 납입·만기 수령 여부, 세금, 연체 및 은행 정산액은 확인하지 않은 예상 현금흐름입니다. 결제수단·납부월 미정인 입주 비용은 제외하며 과거 급여 변경이력은 관리하지 않으며, 고정비는 등록한 적용 기간에 따라 계산합니다(기존 등록 고정비는 매월 반복). 월급 외 수입은 등록한 일자 또는 반복 일정 기준입니다.

월별 상세 내역

아파트 입주 준비 · 계약 및 지출 관리

중문·시스템에어컨·가전·가구·입주청소·이사·등기처럼 입주 전 준비할 계약을 관리합니다. 한 계약의 계약금·중도금·잔금을 각각 등록하고, 지급 단계별로 현금·카드 일시불·카드 할부·미정 중 결제수단을 선택할 수 있습니다.

아파트 입주 비용은 6번 메뉴에서만 입력하세요. 3번 카드할부나 1번 변동지출에 같은 금액을 중복 등록하면 전체 현금흐름에 이중 반영됩니다. 카드할부는 첫 청구월부터 반영하고, 미정이거나 지급일/첫 청구월을 입력하지 않은 금액은 월별 현금흐름에서 제외합니다.

계약·납부·시공 일정

입주 계약 항목 등록

지급 일정과 결제수단

각 지급 단계에 금액을 입력하면 합계가 계약 총액이 됩니다. 아직 일정이나 결제수단이 확정되지 않았다면 비워두거나 ‘미정’을 선택해 두었다가 수정할 수 있습니다.

입주 비용 월별 지출 계획

현금은 지급 예정일이 포함된 월에, 카드는 첫 청구월부터 반영합니다. 할부는 무이자 할부 가정으로 금액을 나누며 마지막 달에 원 단위 차액을 보정합니다. 카드 수수료·할부이자·실제 카드사 청구일은 반영하지 않습니다.
